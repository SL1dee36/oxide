# Модуль `math` — Линейная алгебра и геометрические вычисления

Модуль `math` предоставляет математический аппарат для пространственных вычислений, реэкспортируя векторные, матричные и кватернионные типы из высокопроизводительной SIMD-библиотеки `glam`, а также константы точности и функции конвертации угловых единиц.

Исходный код: [`src/math/`](../../src/math/)

---

## 1. Системы координат

В архитектуре Oxide используются две строго разделенные системы координат:

```mermaid
graph LR
    subgraph Space3D [Трехмерное мировое пространство (3D World Space)]
        AxisX3D["Ось +X: вправо"]
        AxisY3D["Ось +Y: вверх"]
        AxisZ3D["Ось +Z: назад (камера направлена в -Z)"]
    end

    subgraph Space2D [Двумерное экранное пространство (2D Screen Space)]
        AxisX2D["Ось +X: вправо [0, width]"]
        AxisY2D["Ось +Y: вниз [0, height]"]
        Origin2D["Начало координат (0, 0): левый верхний угол экрана"]
    end
```

### 1.1. Трехмерное пространство (Правосторонняя система, Right-Handed):
- Используется для графа сцены (`spatial::Scene`), 3D мешей (`Mesh3D`), коллидеров (`Collider::Box3D`, `Collider::Sphere`) и лучей (`Ray3D`).
- **Оси:** $+X$ — вправо, $+Y$ — вверх, $+Z$ — назад (вектор взгляда перспективной камеры по умолчанию направлен вдоль оси $-Z$).
- **Матрицы вида и проекции:** Формируются вызовами `Mat4::look_at_rh` и `Mat4::perspective_rh_gl`.

### 1.2. Двумерное экранное пространство (Screen Space):
- Используется для плоских поверхностей (`Surface2D`), экранного текста (`Text2D`) и двумерных ограничивающих рамок (`Aabb2D`).
- **Оси:** Начало координат $(0, 0)$ расположено в **левом верхнем углу** окна. Ось $+X$ направлена вправо $[0, \text{width}]$, ось $+Y$ направлена вниз $[0, \text{height}]$.
- **Ортографическая матрица:** Формируется вызовом `Mat4::orthographic_rh_gl(0.0, width, height, 0.0, -1.0, 1.0)`.

## 2. Реэкспортируемые типы (`glam`)

Модуль реэкспортирует базовые линейно-алгебраические примитивы `glam`:

| Тип | Описание | Размер и выравнивание |
| :--- | :--- | :--- |
| `Vec2` | Двумерный вектор с компонентами `x, y: f32`. | 8 байт, выравнивание 4 байта |
| `Vec3` | Трехмерный вектор с компонентами `x, y, z: f32`. | 12 байт, выравнивание 4 байта |
| `Vec4` | Четырехмерный вектор с компонентами `x, y, z, w: f32`. | 16 байт, SIMD-выравнивание 16 байт |
| `Quat` | Кватернион ориентации `x, y, z, w: f32` (единичный). | 16 байт, SIMD-выравнивание 16 байт |
| `Mat2` | Матрица $2 \times 2$ с порядком столбцов column-major. | 16 байт |
| `Mat3` | Матрица $3 \times 3$ с порядком столбцов column-major. | 36 байт |
| `Mat4` | Аффинная матрица преобразования $4 \times 4$ column-major. | 64 байта, SIMD-выравнивание 16 байт |

Реэкспортируются также удобные функции-конструкторы: `vec2(x, y)`, `vec3(x, y, z)`, `vec4(x, y, z, w)`.

## 3. Константы и угловые единицы

```rust
pub const EPSILON: f32 = 1e-5;

#[inline]
pub fn deg_to_rad(deg: f32) -> f32;

#[inline]
pub fn rad_to_deg(rad: f32) -> f32;
```

### Единицы измерения:
- Все внутренние угловые аргументы функций движка (`rotate_x`, `rotate_y`, `rotate_z`, `fov_y_rad` в `Projection::Perspective`) принимают значения в **радианах**.
- Функции создания камер (`Camera::perspective`) принимают поле зрения по вертикали в **градусах** для удобства конфигурации и автоматически переводят их в радианы с помощью `deg_to_rad`.
- `EPSILON = 1e-5` применяется в численных сравнениях контактных манифолдов, нормализации векторов и проверке деления на ноль.
