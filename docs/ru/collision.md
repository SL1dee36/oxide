# Модуль `collision` — Геометрическая детекция коллизий, OBB/SAT, Broadphase и лучевые запросы

Модуль `collision` предоставляет высокопроизводительные алгоритмы геометрической детекции пересечений (Collision Detection), ориентированные параллелепипеды (`Obb3D`) на базе теоремы о разделяющей оси (SAT), консервативную широкую фазу коллизий (`BroadphaseGrid`), кинематическое расталкивание тел и трассировку лучей (Raycasting).

Исходный код: [`src/collision/`](../../src/collision/)

---

## 1. Связь сущностей ECS и коллидеров

В ECS-архитектуре Oxide коллидеры хранятся в таблице компонентов `world.collider: SecondaryMap<EntityId, Collider>`.

В момент проверки коллизий форма `Collider` трансформируется в мировое пространство с использованием матрицы `world.global_transform_matrix(entity)`:
- Для **Box3D**: создается ориентированный параллелепипед `Obb3D::from_matrix`, точно сохраняющий углы вращения и масштаб без раздувания геометрии.
- Для **Sphere**: центр сферы переносится матрицей в мировую точку `matrix.transform_point3(Vec3::ZERO)`, а радиус масштабируется максимальным коэффициентом масштаба.
- Для **Box2D**: габариты и позиция масштабируются трансляцией и масштабом в экранных пикселях.

## 2. Ограничивающие объемы (`Collider`)

Перечисление `Collider` задает геометрию в локальных координатах сущности:

```rust
pub enum Collider {
    Box3D { half_extents: glam::Vec3 },
    Sphere { radius: f32 },
    Box2D { half_extents: glam::Vec2 },
}
```

### Конструкторы и методы:
- `Collider::box_3d(size: Vec3) -> Self` — принимает полные размеры `(dx, dy, dz)` и сохраняет полуразмеры `size * 0.5`.
- `Collider::sphere(radius: f32) -> Self` — задает сферу радиуса `radius`.
- `Collider::box_2d(size: Vec2) -> Self` — задает плоский экранный прямоугольник.
- `Collider::world_aabb(&self, matrix: &Mat4) -> Aabb3D` — рассчитывает консервативный мировой осевой AABB для алгоритмов широкой фазы.

## 3. Математические объемы

### `Obb3D` (Ориентированный параллелепипед)
```rust
pub struct Obb3D {
    pub center: Vec3,
    pub axes: [Vec3; 3],       // Ортонормированные локальные оси X, Y, Z в мировом пространстве
    pub half_extents: Vec3,  // Масштабированные полуразмеры
}
```
- `from_matrix(half_extents: Vec3, matrix: &Mat4) -> Self` — извлекает масштаб, вращение и положение, строя честный OBB.
- `contact(&self, other: &Self) -> Option<ContactManifold>` — точное пересечение OBB vs OBB по **теореме о разделяющей оси (SAT)** с проверкой 15 потенциальных осей разделения (6 граней + 9 взаимных векторных произведений ребер).
- `contact_sphere(&self, sphere: &BoundingSphere) -> Option<ContactManifold>` — точное пересечение со сферой переводом центра сферы в локальный базис OBB.
- `raycast(&self, ray: &Ray3D) -> Option<RaycastHit>` — перевод луча в локальное пространство OBB и тест плит (Slab method).

### `Aabb3D` (Осевой параллелепипед)
```rust
pub struct Aabb3D {
    pub min: Vec3,
    pub max: Vec3,
}
```
Используется для консервативного охвата геометрии в алгоритмах широкой фазы (`BroadphaseGrid`), отсечения непересекающихся пар и пространственного поиска.

### `BoundingSphere` (Ограничивающая сфера)
```rust
pub struct BoundingSphere {
    pub center: Vec3,
    pub radius: f32,
}
```
- `intersects(&self, other: &Self) -> bool` — проверка перекрытия через квадрат расстояния: $\|\mathbf{c}_1 - \mathbf{c}_2\|^2 \le (r_1 + r_2)^2$.
- `contact(&self, other: &Self) -> Option<ContactManifold>` — манифолд соприкосновения двух сфер.

## 4. Широкая фаза (`BroadphaseGrid` — Sort-and-Sweep)

Для исключения квадратичной сложности $O(N^2)$ при проверке сотен объектов модуль предоставляет этап широкой фазы на базе алгоритма Sort-and-Sweep (Sweep-and-Prune):

```rust
pub struct BroadphaseGrid {
    proxies: Vec<BroadphaseProxy>,
    pairs: Vec<BroadphasePair>,
}
```

1. Для каждого живого коллайдера формируется мировой консервативный `Aabb3D`.
2. Прокси-объекты сортируются по минимальной координате `min.x` за $O(N \log N)$.
3. Сканирование вдоль оси X отсекает до 99.9% удаленных пар до выполнения ресурсоемких тригонометрических проверок.
4. Пары, состоящие из двух неподвижных (статических) объектов, отсекаются немедленно.
5. Для оставшихся потенциальных кандидатов запускается узкая фаза детекции коллизий.

## 6. Кинематическое разделение тел (`resolve_penetration_system`)

Устраняет взаимное проникновение двух пересекающихся сущностей вдоль нормали контакта:
- **Оба тела динамические:** Смещение разделяется поровну (50% / 50%).
- **Одно тело статическое:** Статическое препятствие остается на месте, а динамическое тело смещается на 100% глубины.
- **Оба тела статические:** Смещение игнорируется.

## 7. Трассировка лучей (`Ray3D`, `RaycastHit`)

```rust
pub struct Ray3D {
    pub origin: Vec3,
    pub direction: Vec3, // Автоматически нормализуется
}

pub struct RaycastHit {
    pub distance: f32,   // Параметрическое расстояние t >= 0.0
    pub point: Vec3,      // Мировая точка попадания
    pub normal: Vec3,     // Нормаль к поверхности в точке удара
}
```

Система `raycast_system(world: &World, ray: &Ray3D) -> Option<(EntityId, RaycastHit)>` тестирует луч против всех видимых сущностей с коллидерами и возвращает ближайшее попадание.
