# Модуль `collision` — Геометрическая детекция коллизий и лучевые запросы

Модуль `collision` предоставляет алгоритмы геометрической детекции пересечений (Collision Detection), аналитического формирования контактных манифолдов, кинематического устранения взаимного проникновения тел и трассировки лучей (Raycasting).

> **Примечание об архитектуре:** Модуль `collision` является системой геометрической детекции пересечений, а **не физическим движком динамики твердых тел**. В нем отсутствуют расчет импульсов, тензоры инерции, силы трения и солверы динамических ограничений. Модуль выполняет только геометрические запросы и кинематическое разделение объемов.

Исходный код: [`src/collision/`](../../src/collision/)

## 1. Связь пространственных трансформаций и коллидеров

Каждый узел графа сцены (`SpatialNode`) хранит локальный ограничивающий объем `collider: Option<Collider>`.

В момент проверки коллизий форма `Collider` трансформируется в мировое пространство с использованием матрицы `SpatialNode::global_matrix()`:
- Для **Box3D**: локальный параллелепипед преобразуется матрицей $4 \times 4$ в охватывающий мировой параллелепипед `Aabb3D` с пересчетом полуразмеров через модули элементов матрицы.
- Для **Sphere**: центр сферы переносится матрицей в мировую точку `matrix.transform_point3(Vec3::ZERO)`, а радиус берется с учетом однородного масштаба.
- Для **Box2D**: габариты и позиция масштабируются трансляцией и масштабом узла в экранных пикселях.

## 2. Ограничивающие объемы (`Collider`)

Перечисление `Collider` задает геометрию в локальных координатах узла:

```rust
pub enum Collider {
    Box3D { half_extents: glam::Vec3 },
    Sphere { radius: f32 },
    Box2D { half_extents: glam::Vec2 },
}
```

Конструкторы:
- `Collider::box_3d(size: Vec3) -> Self` — принимает полные размеры `(dx, dy, dz)` и сохраняет полуразмеры `size * 0.5`.
- `Collider::sphere(radius: f32) -> Self` — задает сферу радиуса `radius`.
- `Collider::box_2d(size: Vec2) -> Self` — принимает полные размеры `(w, h)` в экранных пикселях и сохраняет полуразмеры `size * 0.5`.

## 3. Математические объемы

### `Aabb3D` (Ориентированный на оси параллелепипед)
```rust
pub struct Aabb3D {
    pub min: Vec3,
    pub max: Vec3,
}
```
- `from_center_half_extents(center: Vec3, half_extents: Vec3) -> Self`
- `transform(&self, matrix: &Mat4) -> Self` — строит консервативный мировой AABB для произвольной матрицы трансформации.
- `intersects(&self, other: &Self) -> bool` — тест пересечения по интервалам проекций на оси X, Y, Z.
- `contact(&self, other: &Self) -> Option<ContactManifold>` — вычисляет ось минимального перекрытия, глубину проникновения и нормаль разделения.
- `contact_sphere(&self, sphere: &BoundingSphere) -> Option<ContactManifold>` — тест пересечения AABB со сферой (поиск ближайшей точки).

### `BoundingSphere` (Ограничивающая сфера)
```rust
pub struct BoundingSphere {
    pub center: Vec3,
    pub radius: f32,
}
```
- `intersects(&self, other: &Self) -> bool` — проверка перекрытия через квадрат расстояния между центрами: $\|\mathbf{c}_1 - \mathbf{c}_2\|^2 \le (r_1 + r_2)^2$.
- `contact(&self, other: &Self) -> Option<ContactManifold>` — генерирует нормаль разделения вдоль вектора между центрами сфер.

### `Aabb2D` (Двумерный экранный AABB)
```rust
pub struct Aabb2D {
    pub min: Vec2,
    pub max: Vec2,
}
```
Аналитическое пересечение плоских прямоугольников в экранных координатах.

## 4. Контактный манифолд (`ContactManifold`)

При обнаружении геометрического пересечения формируется структура `ContactManifold`:

```rust
pub struct ContactManifold {
    pub normal: glam::Vec3,
    pub depth: f32,
    pub point: glam::Vec3,
}
```

- **`normal: Vec3`**: Единичный вектор оси минимального разделения, направленный от тела A к телу B.
- **`depth: f32`**: Глубина проникновения вдоль вектора нормали ($> 0.0$).
- **`point: Vec3`**: Точка контакта в мировой системе координат.

## 5. Кинематическое разделение тел (`resolve_penetration`)

Устраняет взаимное проникновение двух пересекающихся узлов сцены без динамического моделирования сил:

```rust
pub fn resolve_penetration_weighted(
    transform_a: &mut Transform,
    is_static_a: bool,
    transform_b: &mut Transform,
    is_static_b: bool,
    contact: &ContactManifold,
);
```

### Правила распределения смещения:
1. **Оба тела динамические (`is_static == false`):** Смещение разделения делится поровну между обоими телами (50% / 50%):
   $$\mathbf{T}_a \leftarrow \mathbf{T}_a - \mathbf{n} \cdot \frac{d}{2}, \quad \mathbf{T}_b \leftarrow \mathbf{T}_b + \mathbf{n} \cdot \frac{d}{2}$$
2. **Одно тело статическое (`is_static == true`):** Статическое препятствие остается неподвижным ($0\%$), а динамическое тело получает полное смещение на 100% глубины контакта ($d$).
3. **Оба тела статические:** Смещение игнорируется.

## 6. Трассировка лучей (`Ray3D`, `RaycastHit`)

Используется для пространственных запросов, выбора объектов и определения линии взгляда:

```rust
pub struct Ray3D {
    pub origin: Vec3,
    pub direction: Vec3, // Автоматически нормализуется
}

pub struct RaycastHit {
    pub distance: f32,  // Параметрическое расстояние t >= 0.0
    pub point: Vec3,     // Мировая точка пересечения
    pub normal: Vec3,    // Внешняя нормаль к поверхности в точке удара
}
```

- **Метод плит (Slab Method):** `Aabb3D::raycast` вычисляет аналитическое пересечение луча с гранями AABB.
- **Квадратичный метод:** `BoundingSphere::raycast` решает квадратное уравнение пересечения луча со сферой.
- **Запрос по сцене:** `Scene::raycast(&self, ray: &Ray3D) -> Option<(NodeId, RaycastHit)>` обходит все видимые узлы с коллидерами и возвращает узел с наименьшим значением дистанции `distance`.
