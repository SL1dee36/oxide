# Модуль `text` — Типографика и рендеринг шрифтов

Модуль `text` обеспечивает высокоскоростную растеризацию векторных шрифтов (TTF/OTF), генерацию динамических текстурных атласов и рендеринг текста с поддержкой кириллицы и латиницы.

Исходный код: [`src/text/`](file:///e:/PRJCT/Oxide/src/text/)

## 1. Загрузка шрифтов (`Font`)

Интеграция с библиотекой `fontdue` обеспечивает парсинг глифов:

```rust
// Загрузка из файла
let custom_font = Font::from_file("assets/fonts/my_font.ttf")?;

// Загрузка из среза памяти (например, include_bytes!)
let mem_font = Font::from_bytes(FONT_BYTES)?;

// Автоматический fallback (локальный каталог либо шрифты ОС)
let default_font = Font::default_font()?;
```

## 2. Текстурный атлас (`FontAtlas`)

При создании `FontAtlas::new(gl, font, font_size)`:
1. Выделяется текстурный массив размером `1024x1024` пикселей.
2. Выполняется растеризация символов:
   - Полный диапазон ASCII (`32..=126`).
   - Расширенная кириллица (`0x0400..=0x045F`: А-Я, а-я, Ё, ё).
   - Типографические символы (`№`, `«`, `»`, `—`, `–`, `°`, `±`, `•`, `…`).
3. Глифы упаковываются алгоритмом полочной упаковки (Shelf Packing).
4. Создается текстура `Texture2D`, где значение альфа-канала соответствует степени покрытия пикселя глифом.

### Расчет размеров строки:
```rust
let size: Vec2 = atlas.measure_text("Строка для расчета ширины и высоты");
```

## 3. Дескриптор текста (`Text2D`)

Структура для описания текстового элемента:

```rust
let text = Text2D::new("Статус: Активен")
    .with_color(Color::rgb(0.2, 0.8, 1.0))
    .with_scale(1.2);
```

---

## 4. Шейдерный конвейер текста (`PipelineText`)

- **Шейдер:** Вычисляет прозрачность на основе альфа-канала атласа: `o_color = vec4(u_color.rgb, u_color.a * texture(u_atlas, v_uv).a)`.
- **Батчинг:** Все символы строки объединяются в один буфер вершин и индексов (4 вершины и 6 индексов на глиф) и выводятся за один вызов `glDrawElements`.
- **Интеграция со сценой:**
  ```rust
  // Назначение кастомного атласа
  scene.set_font_atlas(Arc::new(atlas));

  // Спавн текстового узла
  let node_id = scene.spawn_text_2d(text, Transform::from_xyz(40.0, 50.0, 0.0));
  ```
